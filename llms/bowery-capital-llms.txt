# Bowery Capital

> Bowery Capital is a B2B-focused venture capital firm that leads Pre-Seed and Seed rounds in SaaS and marketplace founders "modernizing business through technology," with particular interest in vertical AI and back-office software. It backs companies hands-on through Growth, Talent, Business Development, and a Revenue Council advisory network. This is an API Evangelist network profile for the firm; Bowery Capital is an investor, not an API provider, so it publishes no developer API surface.
